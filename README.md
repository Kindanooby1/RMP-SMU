# A Simple RateMyProfessor Extension for SMU

**Get on Chrome here**: Not happening because chrome requires a payment for developer account...

**Get on Firefox here**: [when it gets approved]

On mySMU, implements a direct link to a search of the professor's name on RateMyProfessor (RMP)

Works on the following pages on mySMU:
- Advanced Class Search

**Limitations:**
- If a word in the name contains an apostrophe, will ignore that word when searching.
  - This is because RMP removes special characters when searching.
  - This messes the search up for apostrophes (as far as I can tell)
- Does not import ratings, difficulty, etc.

Not affiliated with SMU or RMP
